## 4. 关键数据模型

### 4.1 消息模型

```python
BaseMessage
├── type: MessageType (TASK_REQUEST/TASK_RESPONSE/NODE_EXECUTE/NODE_RESULT/ERROR/EVENT)
├── payload: Dict[str, Any]
├── sender: str
├── receiver: Optional[str]
├── id: str (UUID)
├── timestamp: datetime
├── metadata: Dict[str, Any]
└── idempotency_key: Optional[str]
```

### 4.2 任务图模型

```python
TaskGraph
├── _nodes: Dict[str, Node]
│   └── Node
│       ├── node_id: str
│       ├── task_type: str
│       ├── dependencies: List[str]
│       ├── status: NodeStatus (PENDING/READY/RUNNING/COMPLETED/FAILED)
│       ├── tool_candidates: List[Dict]
│       ├── execution_strategy: str
│       └── output_keys: List[str]
└── _edges: Dict[str, List[str]]

NodeStatus
├── PENDING   - 等待中
├── READY     - 准备就绪
├── RUNNING   - 执行中
├── COMPLETED - 已完成
└── FAILED    - 执行失败
```

### 4.3 数据获取模型

```python
DataRequest
├── data_key: str
├── description: str
├── required: bool
├── value_schema: Optional[Dict]
├── default_value: Optional[Any]
└── validation_rules: Optional[List[Dict]]

DataResponse
├── value: Any
├── source: DataSource
├── confidence: DataConfidenceLevel
├── timestamp: datetime
├── acquisition_path: List[Dict]
└── metadata: Dict[str, Any]

DataConfidenceLevel
├── MEASURED    - 实测数据 (1.0)
├── CALCULATED  - 计算数据 (0.8)
├── REFERENCE   - 参考数据 (0.6)
├── ESTIMATED   - 估算数据 (0.4)
```

## 7. 设计模式应用

| 模式 | 应用位置 | 说明 |
|------|----------|------|
| **策略模式** | `BaseAgent.strategy` | 可替换的执行策略 |
| **模板方法模式** | `BaseAgent.execute()` | 定义算法骨架，子类实现细节 |
| **工厂模式** | `ToolRegistry` | 工具注册和创建 |
| **观察者模式** | `ClarificationManager.on_resume` | 恢复执行回调 |
| **适配器模式** | `InputAdapter` 系列 | 统一不同输入格式接口 |
| **责任链模式** | `ChainOptimizer` | 多阶段链路优化 |
| **状态模式** | `NodeStatus`, `AgentStatus` | 状态管理 |
